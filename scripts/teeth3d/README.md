# 3D-модели зубов

Генератор собирает модели всех типов зубов в GLB без внешних зависимостей:
форма описывается полем расстояний по анатомическим размерам, сетка строится
методом surface nets. Сканов и чужих моделей внутри нет.

```bash
node scripts/teeth3d/generate.mjs
node scripts/teeth3d/generate.mjs --only 16,46 --preview ./tmp --debug
```

Результат — `public/models/teeth/`: 26 типов зубов, по два файла на тип.

| Файл | Для чего | Треугольников |
|---|---|---|
| `<fdi>.glb` | один зуб крупно, шторка зуба | 2–12 тыс. |
| `<fdi>-lo.glb` | вся челюсть сразу | 0,5–3 тыс. |

Типы: постоянные `11–18`, `41–48`, молочные `51–55`, `81–85`. Размеры —
средние по Wheeler's Dental Anatomy, лежат в `anatomy.mjs`.

## Устройство модели

- Единица — миллиметр. Y вверх к режущему краю, Y = 0 на эмалево-цементной
  границе, +X мезиально, +Z вестибулярно.
- Корневой узел `tooth-<fdi>`, дочерние узлы по поверхностям карты:
  `I` или `O`, `M`, `D`, `V`, `L`, `root`. Имена совпадают с `ALL_SURFACES`
  в `src/lib/constants/teeth.ts`, поэтому поверхность красится по записи
  без таблиц соответствия.
- Материалы `enamel` и `root`.
- Кроме поверхностей в модели всегда есть детали, скрытые по умолчанию:
  `crown` — колпачок коронки (поле зуба, раздутое на 0,35 мм и срезанное у шейки,
  материал `ceramic`), `implant` — титановый винт с абатментом на оси зуба вместо
  корня, `canals` — пломбированные каналы вдоль осей корней (`gutta`). Каналы и
  имплант строятся сеткой напрямую (`extras.mjs`): канал тоньше шага полигонизации.
  Когда их показать, решает `src/components/odontogram/model3d.ts`.
- Вершины сжаты по `KHR_mesh_quantization`: координаты int16 с масштабом и сдвигом на
  узле части, нормали int8 — вдвое меньше данных, челюсть грузит 16 файлов разом.
  three.js читает расширение сам; сторонний просмотрщик без его поддержки файл не откроет.

Модель описывает правую сторону. Остальные квадранты получаются так:

| Квадрант | Преобразование |
|---|---|
| 4, 8 — нижняя правая | как есть |
| 3, 7 — нижняя левая | `scale.x = -1` |
| 1, 5 — верхняя правая | `scale.y = -1`, коронкой вниз |
| 2, 6 — верхняя левая | поворот на 180° вокруг Z |

Отрицательный масштаб переворачивает обход треугольников; three.js учитывает
это сам по знаку определителя матрицы.

## Перед подключением к сайту

Middleware пропускает без редиректа только картинки и ресурсы PWA. Чтобы модели
открывались анониму на лендинге, в `matcher` из `src/middleware.ts` нужно
добавить расширение `glb`. Иначе запрос получит 307 на `/login`.

## Реалистичные сканы как альтернатива

Коллекция [Dundee Tooth Morphology](https://sketchfab.com/DundeeDental/collections/dundee-tooth-morphology-574c456663334fe89c78503a975dc946)
от University of Dundee, School of Dentistry: 16 постоянных зубов и два
варианта первого верхнего моляра под лицензией CC BY. Её можно использовать
в коммерческом продукте с указанием авторства. Скачивание требует аккаунта
Sketchfab. В каждой модели 21–50 тыс. треугольников, разметки поверхностей
нет, молочных зубов нет. Эндодонтические варианты из коллекции не скачиваются.

Не подходят для платного продукта из-за лицензии NonCommercial: Mandible от
DundeeDental, Adult Tooth Morphology от ushefdentistry, Dente 36 от opendentistry.
